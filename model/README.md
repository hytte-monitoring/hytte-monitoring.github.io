# model/

| Content | Status |
|---------|--------|
| `class-diagram/`, `statemachine-diagram/`, `sequence-diagram/`, `use-case-diagram/`, `activity-diagram/` | **Frozen.** The assignment 1 diagrams, kept as the starting point. They are not edited any more |
| `adr/` | **Living.** Changed only on a team decision |
| `Team_Guide.md` | The fallback when a diagram or ADR is unclear |

The **official model** for class, state and sequence diagrams is
`project/diagrams/conversion/*.mmd`, the version the verifier checks. Every
change to it since the conversion is a team decision, logged in
`project/reports/deviations.md` (F01–F16). Rules: [CLAUDE.md](../CLAUDE.md#ground-truth).

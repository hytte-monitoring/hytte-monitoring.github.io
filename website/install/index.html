Install firmware

Install Hytte on your micro:bit

Do this once. The program stays on the micro:bit, so next time you only plug it in and open the dashboard.

  1. Plug in your micro:bit

    Connect it to this computer with a USB cable. A new drive called MICROBIT appears, like a USB stick.

  2. Download the Hytte program

    Download Hytte for micro:bit

    Tip: if your browser asks where to save the file, choose the MICROBIT drive. Then you can skip step 3.

  3. Copy it onto the micro:bit

    Open your Downloads folder and drag hytte-monitoring.hex onto the MICROBIT drive. The yellow light on the back of the micro:bit blinks. Wait until it stops.

  4. Open the dashboard

    Go to the dashboard and click Connect micro:bit. The board shows ? and the page says "Connected".

    Use Chrome, Edge or Firefox (version 151 or newer) on a computer. On Linux, a browser installed as a snap or Flatpak cannot reach the micro:bit.

Using a terminal (optional)

Paste the command for your system into a terminal (for example VS Code's). It downloads the program from this page and copies it onto the MICROBIT drive (steps 2 and 3 in one).
